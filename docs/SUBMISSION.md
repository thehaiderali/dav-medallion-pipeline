# Phase 1 submission checklist

1. **Proposal document** — Submit [`project-proposal.md`](project-proposal.md) (or export to PDF). It covers all six Phase 1 sections.
2. **GitHub** — Push this repo and put the public URL on the proposal cover (replace `YOUR_USERNAME` in the README clone URL).
3. **Sample data** — Already in [`../sample_data/`](../sample_data/):
   - `full_load_sample.csv` — full-load payload (~12,550 rows, ~2.1 MB)
   - `incremental_load_sample.csv` — last 5 trading days × 10 tickers (50 rows)

No pipeline code is required for Phase 1; Bronze/Silver/Gold folders contain README stubs for Phase 2.
